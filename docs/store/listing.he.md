# Inkshot — תיאור לחנות (he)

- **שם**: Inkshot
- **כותרת משנה** (≤30): צילומי מסך, סימונים וגלילה
- **מילות מפתח** (≤100): `צילום מסך,סימון,חץ,מרקר,טשטוש,דף אינטרנט,דף מלא,לוח,זכוכית מגדלת,הערות`
- **טקסט קידום**: מצלמים הכול, מסמנים בשניות ומדביקים בכל מקום — גם דפי אינטרנט שלמים.

## תיאור

Inkshot נמצא בשורת התפריטים. לוחצים ⌘⇧P הימני, בוחרים אזור, חלון, מסך מלא, חלון עם גלילה או דף
אינטרנט שלם — והצילום כבר בלוח.

העורך נפתח מיד: חצים, מסגרות, טקסט, מספרי שלבים, מרקר שנראה גם באפליקציות כהות, טשטוש לפרטים
אישיים וחיתוך. כל שינוי מתעדכן בלוח.

- צילום עם גלילה: Inkshot גולל את החלון בעצמו ומחבר תמונה אחת רציפה.
- דף אינטרנט מלא: כל אתר בשלמותו, ברוחב מחשב או טלפון.
- זכוכית מגדלת ודוגם צבע.
- היסטוריה עם הצמדה.
- אנגלית, רוסית ועברית.

ללא חשבונות וללא מעקב: הצילומים נשארים ב־Mac שלך.
