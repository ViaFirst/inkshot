# Inkshot — описание для магазина (ru)

- **Название**: Inkshot
- **Подзаголовок** (≤30): Скриншоты, пометки, прокрутка
- **Ключевые слова** (≤100): `снимок экрана,скрин,аннотации,стрелка,маркер,размытие,веб-страница,вся страница,буфер,лупа`
- **Промо**: Снимай что угодно, размечай за секунды, вставляй куда нужно — даже целые веб-страницы.

## Описание

Inkshot живёт в строке меню. Нажми правый ⌘⇧P, выбери область, окно, весь экран, окно с прокруткой
или всю веб-страницу — снимок уже в буфере обмена.

Сразу открывается редактор: стрелки, рамки, текст, номера шагов, маркер, который виден и в тёмных
приложениях, размытие для личных данных, обрезка. Каждое изменение сразу попадает в буфер.

- Скрин с прокруткой: листай окно в своём темпе, Inkshot склеит картинку без швов.
- Вся веб-страница: любой сайт целиком, в ширине компьютера или телефона.
- Лупа и пипетка.
- История с закреплением.
- Английский, русский и иврит.

Без аккаунтов и слежки: снимки остаются на твоём Mac.
